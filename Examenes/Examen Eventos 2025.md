# Evaluación integradora 2 - Laboratorio de Programación

## 1. Selección, creación y aplicación de elementos

Seleccione un elemento HTML utilizando JavaScript. Luego, cree un nuevo elemento desde el mismo archivo JavaScript y añádalo dentro del primer elemento seleccionado.

## 2. Evento clic

Aplique un escucha de evento `click` a un elemento previamente seleccionado. Al hacer clic sobre dicho elemento, su color de fondo debe cambiar a rojo.

## 3. Evento tecla

Aplique un escucha de evento de teclado al cuerpo de un documento HTML. Al presionar la tecla `r`, el color de fondo debe cambiar a rojo. Si la tecla se vuelve a presionar, el fondo debe regresar a su color predeterminado (blanco).
